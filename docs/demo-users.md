# Два демонстрационных аккаунта

После загрузки кода на сервер, из каталога приложения:

```sh
/opt/php/8.4/bin/php artisan demo:create
```

Команда создаёт `demo_basic` и `demo_premium`, печатает случайные пароли и табельные номера. Сохраните пароли: они хранятся только в виде хешей. Повторный запуск не меняет существующие аккаунты.

У каждого аккаунта вымышленный профиль, семь заданий на ближайшие недели и три завершённых события хронологии. У `demo_premium` доступ на 365 дней от даты запуска, у `demo_basic` — базовая версия. Календарная ссылка премиума создаётся штатно при входе.

Оба имеют должность «Рядовой пилот», доступ к личному кабинету и просмотр трёх отчётов без импорта и администрирования. Отчёты не заполняются: для вымышленных ФИО и табельных они пусты; общие фильтры остаются настоящими. Базовый аккаунт видит стандартные ограничения подписки.

Учётные данные портала, Telegram, задачи парсера и подписки push не создаются. Демо-премиум помечен источником `demo`, суммой 0 и комментарием: это не реальная оплата. Для обязательного поля автора используется сам демоаккаунт, а не настоящий администратор.
